Projectile Trajectory



Overview:

A small project to trace the trajectory of a projectile before it is fired.

Role:

Wrote the code to draw a trajectory for a projectile using physics and raycasts to determine collisions in Unity. Any rigid bodies shot from the starting point with the same initial velocity will follow the expected trajectory.





The code allows for a non-standard gravity that can be set in editor using a vector3.

  • Date: Nov 2020 - Jan 2021
  • Software: Unity (C#)
