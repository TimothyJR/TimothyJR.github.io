Burst Particle System



Overview:

This was part of a 2D side scrolling project using C++ and DirectX.

Role:

My role for this project was to make a burst particle system. This was achieved through the use of a geometry shader.

The particle system had various inputs to determine how it will emit particles and how they react over their lifetime. The base emitter was a sphere. It allowed you to determine the number of degrees around the sphere would emit, effectively allowing for hemisphere and point emission. As for particle movement, there were controls for speed and rotation over the lifetime of the emitter. To change the visuals of the particle system, there were settings for particle amount, size over lifetime, color over lifetime, duration of particle lifetime, randomized start rotation and support for an input texture.
