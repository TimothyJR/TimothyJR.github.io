Path Finding



Overview:

A project to show off some of the common path finding algorithms.

Role:

This is a solo project created by me to make sure I knew the common path finding algorithms. The algorithms implemented in this project include breadth first search, depth first search, Dijkstra's, and A* pathfining. The grid will show its progress as it thinks about which path to take until it finds the path to the goal, in which case it will highlight the path that it found.





In addition, I made a custom editor that allows you to change the grid by adding in unpassable tiles. In addition it is also possible to add weight to each tile to affect how the algorithm finds its path.

  • Date: Jan 2021
  • Software: Unity (C#)
