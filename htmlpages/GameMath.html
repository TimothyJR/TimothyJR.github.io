Collisions and Quaternions Projects



Overview:

This is a series of projects that explore various math topics that are useful for game development (Quaternions, Collision Detection, etc).

Role:

The original project here started out as a learning experience on how to do collisions in 3d. It started out with axis-aligned bounding boxes. Then we moved onto oriented bounding boxes using separate axis theorem. From there we worked on optimization using a few different methods. The first was to use layered collision detection. Start with a sphere, move onto an axis aligned bounding box, and then finally check the oriented bounding box if necessary. The second method of optimization was to use an octtree to organize objects to determine if collision checks were even necessary. This was done solo.

The next project evolving form this was a group project. We made a basic game where you jumped from platform to platform looking to reach a goal. My primary role was on creating the text based level editor so we could create a bunch of different levels for the game.




After that, I went to use some of the topics here to create a new project on my own. As I wanted to learn quaternions. So I took what I learned about collision detection and created a quick project with that. Then I wrote a quaternion library that I would use in place of the DirectX Math library to help me understand them. This resulted in a basic project that used my quaternion library to rotate cubes and change their colors when colliding.

  • Date: 2015-2021
