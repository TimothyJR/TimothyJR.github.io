Steering Behaviors and Job System



Overview:

A project to show flocking behavior created in Unity Engine.

Role:

This project is a test of the unity job system using behavioral programming to simulate a flock seeking out a target.





With the separation behavior of the flocking algorithm having no spatial optimization, this project seemed like a good test of the job system in Unity. Before implmenting the job system, the project could manage about 135 flockers at 80 frames per second all interacting with each other in a very simple environment. I ultimately ended up running up to 200 flockers at 80 frames per second. Without the job system, 200 flockers dropped the framerate to single digits. After making some other optimizations, I was able to get the project running with 400 animated butterflies along with an open environment with foliage, trees, particle effects, and more at an average of 60 frames per second.

  • Date: Sep 2016 - Sep 2018
  • Software: Unity (C#)
